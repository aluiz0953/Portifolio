Blog TecnoLógica

Site de notícias focado em Tecnologia, Jogos e Smartphones, desenvolvido como atividade prática. A página foi construída adotando o conceito de Single Page Application (SPA), onde todo o conteúdo é exibido em uma única tela, com navegação suave através de links âncoras no menu principal.

O layout foi desenhado para ser responsivo, utilizando CSS Flexbox para reordenar os elementos no modo móvel. Cores, fontes e espaçamentos foram refinados para proporcionar uma leitura agradável e moderna.

Este Portfólio

Meu primeiro projeto oficial: um portfólio web pessoal. O site foi criado do absoluto zero, utilizando apenas HTML5, CSS3 e JavaScript puro (Vanilla), sem dependência de bibliotecas externas ou templates prontos, para a consolidação dos conceitos base do desenvolvimento web.

A página conta com controle de tema dinâmico (Claro/Escuro) utilizando o LocalStorage do navegador, tem um menu especial responsivo para dispositivos móveis e um formulário de contato integrado e funcional.
